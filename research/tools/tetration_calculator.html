Tetration Explorer

sexpb(x) for continuous bases — via the base atlas (e-anchor + Φ modes), no server, pure table math.
Move the mouse over the plot to read values.
Engine: gp-tetration base atlas (Kneser tetration, fatou.gp by Sheldonison; fork + atlas 2026). Accuracy of this demo: ~6–9 digits (less near the edge b→e^{1/e}); the underlying library delivers up to 972 proven digits.
